클라이언트 메모리 엑셀 통계 분석기

100% 로컬 연산 (보안)

서버 전송 없이 사용자의 브라우저 메모리 안에서만 즉시 계산하고 시각화합니다.

완전한 데이터 보안 보장: 업로드하신 엑셀 파일은 인터넷이나 외부 서버로 일체 전송되지 않습니다. 브라우저의 자바스크립트 엔진 메모리 내에서만 파싱 및 통계 연산이 수행됩니다.

엑셀 파일(.xlsx, .xls)을 여기에 끌어다 놓으세요

또는 클릭하여 내 컴퓨터에서 직접 선택

파일 선택하기
규격 안내 (바탕화면 엑셀 파일 규격 자동 호환)

• 1열은 기준월 (예: 2021-01-01, 2021-01 등 날짜 형태)
• 2열 이후는 각 기업별 매출액(숫자) (예: 한빛테크 매출, 미래솔루션 매출, 새봄산업 매출 등)
• 하단의 연도별 요약이나 설명 행은 통계 왜곡이 없도록 자동으로 똑똑하게 필터링하여 제외합니다.

브라우저 메모리에서 3대 핵심 통계 연산 중...

파일명.xlsx
분석 기간: 2021-01 ~ 2025-12 (60건) · 3개 기업
핵심 3대 통계기법 샘플 모드

기업별 사분위 매출 분포 (최소 ~ 중앙값 ~ 최대)

단위: 억원

각 기업의 60개월 데이터로부터 최소값, Q1(25%), 중앙값(50%), Q3(75%), 최대값을 집계하여 분포를 비교합니다.

기법 #1. 기술통계(Descriptive) 정밀 수치 & 해설

통계 지표

실측 매출 및 OLS 선형회귀 추세선 (y = ax + b)

최소자승법 (OLS)

월별 실측치와 최소자승법(Ordinary Least Squares)으로 도출한 장기 추세선을 겹쳐 장기 성장률과 모델 적합도를 분석합니다.

기법 #2. 선형회귀(Regression) 모델 해설

기업 간 상관관계 산점도 (Scatter Relationship)

상관계수 r (-1 ~ +1)

한 기업의 매출 증감이 다른 기업에 미치는 영향을 산점도로 표현하여 시장 공존/잠식 관계를 도출합니다.

기법 #3. 피어슨 상관계수(Correlation) 해설

메모리에 파싱된 원본 데이터 미리보기 (0건)
